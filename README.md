# MindOverSmoke (智熄) - 经济学人风戒烟认知阻断与返现工具

基于**认知负荷/注意占用理论 (Cognitive Load & Working Memory Absorption)** 与 **行为经济学良性承诺契约 (Commitment Device)** 打造的戒烟微干预工具。

---

## 🌟 核心理念与机制

1. **认知占用理论（拦截 3~5 分钟烟瘾浪涌）**：
   * 急性吸烟冲动（Craving Wave）生理上在 180 秒内达到峰值并自然消退。
   * 通过高难度英语语境、高级词汇完形填空与英式幽默反讽推理，强行占满前额叶皮层的工作记忆，物理切断边缘系统对多巴胺的渴求回路。
2. **《经济学人》(The Economist) 辛辣文风**：
   * 将烟草成瘾比喻为“对肺部的自愿加速折旧”、“向烟草公司按月缴纳生命订阅费”。
   * 包含高级词汇释义（SAT/GRE 级别）、经典反讽判词与语言点拆解，配备生词武器库。
3. **$20 押金 · 每日返 $1 的正向契约模型**：
   * 用户预存 $20，14 天内每天坚持完成阻断打卡返还 $1，累计最高返还 $14。
   * 用户全胜只需自付 $6（相当于少买一包烟）；平台光明正大赚取 $6 技术运营服务费。
   * 彻底摒弃“平台盼着用户失败”的不良心理对立，达成双赢。

开发服务器当前已运行在：

