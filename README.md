## 🧠 核心科学原理与机制

### 1. 认知负荷理论 (Cognitive Load & Working Memory Disruption)
* **180 秒急性浪涌定律**：烟瘾在生理学上表现为边缘系统的多巴胺急性渴求浪涌，其峰值通常持续 3~5 分钟（180 秒）后自然消退。
* **前额叶强行占满**：大脑前额叶皮层的工作记忆容量极其有限（仅约 4~7 个信息块）。MindOverSmoke 拒绝让用户在戒烟时“干熬苦撑”，而是通过高强度的英美权威报刊反讽推理与英汉意象逆向转码，瞬间打满工作记忆，物理切断烟瘾冲动神经回路。

### 2. 三维立体阻断任务闭环 (The Tri-Modal SOS Interventions)
每次触发【🚨 烟瘾急救 · 3分钟阻断 (SOS)】，系统均智能组装三道跨越感知维度的挑战：
1. **任务一：躯体动作或迷走神经激活**
   - 包含 10 个标准俯卧撑、30 秒极速空击等动作，或 4-7-8 深呼吸。
   - 双手撑地从物理上彻底封印摸烟点火的手势肌肉记忆；8 秒超长呼气刺激迷走神经，迅速压低心率与急性交感焦躁；全部动作膝盖友好（Knee-Friendly）。
2. **任务二：古典诗词英汉双向翻译挑战 (100 题)**
   - **Mode 1（英译逆向还原 · 50 题）**：呈现与中文原句对应的参考英译，**不提供中文选项（Zero Multiple Choice）**，由用户根据英文意象回忆原诗。未核实出处的文字不署名为某位译者的作品。
   - **Mode 2（汉诗英译 · 50 题）**：呈现中文原句，由用户自行写出英文译文，提交后对照参考译文，也可直接点击看答案；参考译文中的英文单词可点击查看音标与释义。
3. **任务三：《经济学人》批判反讽精读 (100 题)**
   - 深度拆解成瘾机制背后的商业陷阱与心理投射，以 SAT/GRE 核心词汇完形填空承载事实辨析与反讽推理；选错先提示重试，可主动看答案。
   - **题库总容量达 200 道以上高难度题目**，坚决杜绝任何母语者凭肌肉记忆秒答的“傻瓜单字填空”。

本轮双语题库逐题审核结果见 [双语题库逐题审核记录](./BILINGUAL_REVIEW.md)。

### 3. 14 天无烟挑战（目前为免费体验）
* 正式计划拟收取 $20 计划费。14 个完整自然日内，每天结束后可在随后两个自然日内自报该日是否吸烟。自报无烟的日子申请 $1 原路退款，最多 $14；SOS 做题不影响资格。
* 吸烟或逾期未报的日子不退款，也不会取消之后日期的资格。全胜时平台保留 $6 **毛收入**；未返部分由平台保留，因此实际毛收入可能更高。自报并非客观核验。
* **当前网站未接入支付或退款**：免费体验中的金额只是规则演示，本地记录不是现金凭据，不会收取 $20 或退还 $1。正式开通须先完成服务端支付与退款接入，并公布完整条款。

## 📖 方案 C 双保险秒开离线查词引擎

在阅读复杂的英文批判长难句或古诗英译时，用户随时可以点击任意单词获得辅助：
1. **第一重（本地毫秒直出）**：内置 `fullDictionary.json` 超过 30,000+ SAT/GRE 及学术高频词库与音标映射表，0.001 秒弹窗直出 IPA 国际音标、词性与精炼释义。
2. **第二重（云端静默补全）**：针对罕见专有名词，客户端异步请求免密公开词典 API 并自动存入本地缓存。
3. **第三重（原生划词透传）**：完全兼容用户浏览器自带的翻译插件（如 Edge 侧边栏翻译、沙拉查词），不产生任何事件劫持。
4. **🔇 静音铁律**：弹窗只呈现音标与释义，**绝对静音、严禁自动发音朗读**，杜绝突如其来的音频尴尬。

## 💻 本地开发与启动

### 环境要求
* Node.js >= 18.0.0
* npm >= 9.0.0

### 安装依赖
```bash
npm install
```

### 启动本地开发服务
```bash
npm run dev
```
启动后在浏览器访问控制台提示的本地地址（通常为 `http://localhost:5173/`）。

### 本地生产打包
```bash
npm run build
```
编译产物将安全输出至 `dist/` 目录。

## 🚀 生产部署法则 (Auto-Deployment)

本项目采用严格的**改动即部署**铁律。任何代码改动验证无误后，依次运行以下部署流水线：

```bash
# 1. 编译生产静态包
npm run build

# 2. 推送至当前仓库的 gh-pages 分支
node scripts/deploy_gh_pages.js

# 3. 同步推送至 devastatingroy.github.io 主站 main 分支 (Cloudflare Anycast 源站)
node scripts/deploy_user_site.js

# 4. 提交并同步源代码仓库
git add -A
git commit -m "feat/fix: your commit message"
git push origin master
```
