## 当前规则：完成三题，展示题型可持续轮换（2026-11-08）

- `currentIndex` 只表示本轮已完成题数，仍为 0、1、2；完成第三题后结算一次。SOS 开场仍预置体力、反思和六类挑战中的一项，随机展示首题。预置的后两题只是种子，进入该位置时会被当前题型的下一类覆盖；实际完成题型没有配额。
- 八类循环顺序为体力 → 生活反思 → 呼吸 → 电影台词 → 诗词英译中 → 诗词中译英 → 英文完形 → 中文论断英译 → 体力。任意位置点击「换下一题」都只替换当前题，`currentIndex` 不变；答完点击继续也沿同一顺序选下一题。选择依据是**当前展示题型**，不检查之前完成了什么题型，因此只剩最后一题时仍可跨类轮换。
- 同类题目的 SOS 专用 ID 抽取袋保存在 `localStorage`，优先避开本轮已完成和当前题的 ID；题库只有一道或候选用尽时允许重用，仍不跳过该题型。已有会话的题目、完成数和剩余时间继续存在 `sessionStorage`，刷新保持当前展示题目和已完成前缀。反思题的「换一个方面」只改当前反思内容；「换下一题」切换到下一种题型。
- 日常精读的五题配比及换题规则不变。SOS 仍按三题完成数记录干预，换题不计完成，180 秒倒计时不重置。

## 历史方案（2026-11-06，已被上述规则取代）

## 已核对的现状

- 每轮 SOS 预先生成三项，分别是体力活动、生活反思、轮换挑战，顺序随机。
- 当前 `QuizModal` 用 `currentIndex` 同时表示正在看的题和已完成题数。点击普通题的「换下一题」只调用 `getReplacementTask` 替换当前位置，不移动 `currentIndex`；在体力题上因此连续出现体力题。反思题只提供「换一个方面」，也停留在反思类别。完成当前题并点击继续，才进入另一个位置。第三类挑战本身换题时会优先改变具体题型。
- 现有会话保存题目列表、当前索引、倒计时等。只要已完成题始终位于 `currentIndex` 之前，这个索引本身就是已完成项数；若直接把换题操作改为移动索引，会把未完成题误当成已完成。
- 用题库函数连续替换体力位置五次，实际得到的类别为「体力→体力→体力→体力→体力→体力」。这直接复现了连续不作答时类别不轮换的情况。

## 目标与方案

1. SOS 保留三项类别配比：一项体力、一项生活反思、一项其他挑战。题目顺序仍可随机。日常精读的五项流程维持现状。
2. `currentIndex` 继续表示已完成前缀的长度和当前展示位置。「换下一题」不改变它，也不增加干预次数；只轮转 `questions[currentIndex..末尾]` 这段未完成题。已完成前缀原样保留。
3. 每次跳过当前题时，先取同槽位的新内容：体力换另一动作；反思轮到下一个生活方面；其他挑战从下一种题型及其题目洗牌袋抽取。把未完成片段整体向前轮转一位，再将新内容放到片段末尾。三项类别配比始终保留，也使当前展示的类别改变。
4. 当三个类别都未完成时，连续换题依次看到三个不同类别；再次换题又回到第一类，但内容已更新。完成一项后，换题只在剩余未完成类别中循环。只剩最后一个未完成类别时仍可换该类内容，但无法在保持「三类各完成一项」的前提下再切换类别。此时按钮明确写「换一道同类题」；若最后一项是反思，只保留「换一个方面」。
5. 反思任务同时保留「换一个方面」（只换当前反思内容）和「换下一题」（轮转未完成片段）。阅读即可点击继续；无需填写、评分。完成当前题才使 `currentIndex` 加一；三项全部完成才记录一次 SOS 干预。
6. 继续使用现有 `sessionStorage` 保存题目顺序、`currentIndex` 和倒计时，无须新存储字段或旧会话迁移。刷新后不得把跳过当完成。题型和 ID 轮换继续沿用 `localStorage` 洗牌袋。

## 验收

- 从体力、反思或其他挑战任一位置开始，连续三次「换下一题」都按三个类别循环，进度和干预次数不增加；每次跳过的槽位内容更新，且三项仍各占一类。
- 中途完成一项后，只在剩余未完成类别间换题；最后一项可换同类题，完成后恰好结算一次。
- 换题或完成后刷新当前标签页，不丢展示位置、已完成前缀、反思方面和倒计时。关闭标签页会清除当前 `sessionStorage` 会话，沿用既有行为。
- 日常精读原有换题与五项完成流程，以及中文论断英译、词典和无烟自报不回归。
- 在 390×844 手机模拟视口和 1280×800 PC 模拟视口检查进度、类别、按钮、滚动与关键交互；生产发布后在正式域名核对。模拟结果与真机结果分开说明。
