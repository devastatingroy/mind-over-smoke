# 项目启发的随机任务

## 用途和边界

本轮根据 Roy 最近的穿搭购物参考、旅行影像、逐镜头分析、产品验证、写作表达和职业材料工作，增加八道通用情境任务。题目借用这些工作中的观察和表达动作，不出现项目名称、私人文件或真实职业资料。题库会随公开 PWA 的前端资源一起发布，因此这些题不能承载私人项目进度。

三道「画面想象」进入 SOS：只看当前页面或周围环境，在脑中构造具体画面，不要求打开其他应用、填写或评分。五道「观察与判断」只进入日常精读：保留视频片段、想起一次未购买的原因、向通勤者问一个问题、说清工具的具体优点，以及找出点击率变化的其他可能原因。它们各自只要求做一个选择或说出一件事。流程故障恢复题暂缓，因为它容易引出工作压力。首批任务及示例的唯一内容来源是 `src/data/micro_tasks.json`。

SOS 仍完成三项、开场预置体力和反思，其他挑战抽取池加入画面想象；随后按九类固定顺序换题。日常练习仍完成五项，固定包含反思及至少一道英文思辨题；观察与判断作为其他题型之一轮换。现有活动会话按题目 ID 回读，旧题目继续可用；旧抽取袋会过滤不再适用的 ID，耗尽后进入包含新题型的新一轮。

任务没有输入框，不保存用户针对题目的想法，也不向服务端发送答题内容。用户自行判断是否想好后点击继续，跳过不计完成。画面题的示例默认收起；日常题直接显示示例，帮助用户读懂要做的事。

## 设计依据与未验证处

CDC 和 Smokefree.gov 建议在烟瘾出现时用其他活动分散注意力；这支持提供可立即开始的替代活动，但**不证明这些具体题目能降低烟瘾或提高戒烟成功率**。视觉任务在 SOS 中是否比现有题型更愿意做，需看真实使用反馈，不能从题目机制直接推断效果。

按 Roy 要求，方案形成后使用禁工具、只读的 Claude Opus 5.5 独立评审。Claude 建议将具象画面题与偏工作判断题分开，把前者控制在约一分钟内、后者只放日常；提供示例，避免真实工作资料和购物页面跳转。这些建议已纳入。Claude 还建议同题型换题、可选记录、自定义私人题库和本地统计；本轮保留现有跨类型换题语义，其他功能暂不增加，避免扩大输入、存储与隐私范围。Claude 关于视觉想象可能与烟瘾意象竞争的解释属于理论推断，未作为产品功效文案。

参考：[CDC 戒烟建议](https://www.cdc.gov/tobacco/campaign/tips/quit-smoking/tips-for-quitting/index.html)、[Smokefree.gov 应对烟瘾](https://smokefree.gov/challenges-when-quitting/cravings-triggers/how-manage-cravings)。
